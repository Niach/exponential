## `brand-exponential` icon (#VAPP-283)

The Exponential logo as an icon concept instead of an Image data URL.

| area | change | source of truth | locked by |
|---|---|---|---|
| icon | `brand-exponential` in `packages/icons/icons.json` `custom`: the logo (a disc with three swept stripes cut out, `apps/desktop/assets/icons/logo.svg`) as ONE filled path, four subpaths, no mask, no arcs (M/C/Z only, so every hand-rolled path parser draws it). Disc = r 10 centred in the 24-unit grid like Lucide's circle icons; stripes 1.2 wide (the app-icon variant's 6 on the 100 grid, `logo-white.svg`: the 3.5 of `logo.svg` vanishes below 24 px). `fill: currentColor`, so it tints like every glyph | `icons.json` (regenerated: TS, Swift, Kotlin, Rust, desktop + iOS assets) | the icons generator, `custom-icons.generated.ts` |
| catalog | the Icon `name` vocabulary (`ICON_NAMES`, `core.schema.json`) gains it | `scripts/generate.ts` reads icons.json | generated drift |
| specimen | Icon case `name · non-Lucide` paints it after the OS marks and `progress-2-4` | `fixtures/specimens.json` | every renderer's specimen replay |
| eDE | the panel's launcher button (`apps/ede/ui/panel.json` `menu`) wears `brand-exponential` instead of `nav-apps` | panel.json | `shots/ede-panel` (re-taken on the Linux compositor) |
