Exponential tracks issues in real time and hands them to coding agents that run on your own machines. It syncs across web, desktop, iOS and Android, runs in the cloud at [app.exponential.at](https://app.exponential.at) or on your own server, and is open source under Apache-2.0.

These docs cover the app, the Apps your team builds inside it, the MCP tools and CLI, and the Exponential SDK underneath.
