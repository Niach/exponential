## Packages

Every package publishes together from an `eui-v*` tag.

| Package | Registry | What | Install |
|---|---|---|---|
| `@exponential_app/eui` | npm | The catalog, themes, TypeScript reducer, host API and conformance suite. | `npm install @exponential_app/eui` |
| `@exponential_app/eui-react` | npm | The React renderer and its shadcn primitive set, with a compiled stylesheet. | `npm install @exponential_app/eui-react` |
| `@exponential_app/eui-solid` | npm | The SolidJS renderer and the same primitives, with the same DOM and stylesheet as React. | `npm install @exponential_app/eui-solid` |
| `@exponential_app/eui-element` | npm | The custom element `<exponential-surface>`: the Solid painter inside a web component, for pages without a framework. | `npm install @exponential_app/eui-element` |
| `eui-core` | crates.io | The Rust core: reducer, themes, taffy layout, layers, lists. | `cargo add eui-core` |
| `exponential-ui-ffi` | bundled | The UniFFI facade. It ships inside the Swift and Kotlin artifacts, so you never install it on its own. | nothing to install |
| `eui-gpui` | git | The gpui painter. It stays a git dependency until gpui itself is on crates.io. | a git dependency on github.com/Niach/exponential |
| `ExponentialUI` | SwiftPM | The SwiftUI painter (iOS 17, macOS 14), from github.com/Niach/exponential-ui-swift. | `.package(url: "https://github.com/Niach/exponential-ui-swift", from: "0.20.0")` |
| `at.exponential:eui-compose` | Maven Central | The Compose painter (minSdk 26), with ui-compose-primitives. | `implementation("at.exponential:eui-compose:0.20.0")` |

## Compiled in CI

The guides show the files in [packages/exponential-ui/guides](https://github.com/Niach/exponential/blob/master/packages/exponential-ui/guides) as they are. `guides/check.ts` builds each in an empty temp directory from the packed npm packages, the Swift package, local Maven artifacts and path crates:

```sh
bun packages/exponential-ui/guides/check.ts react   # or solid, element, agent, define, theme, swift, compose, gpui, all
```

The [samples](https://github.com/Niach/exponential/blob/master/samples/exponential-ui) are complete apps: web, iOS, Android and gpui hosts against one local A2UI server, with a third-party theme and an extension component.
