## Install

`at.exponential:eui-compose` is the genUI module for Compose.

One Maven artifact, `at.exponential:eui-compose` (minSdk 26). Its POM brings the primitives, Compose, coroutines and JNA, and the AAR carries the Rust core for arm64-v8a, armeabi-v7a and x86_64. R8 needs no extra rules.

```kotlin
dependencies {
    implementation("at.exponential:eui-compose:0.21.0")
}
```

It resolves from `mavenCentral()`. The whole dependency block of the guide's app:

## Paint a surface

One `ExponentialHost` per activity, connected in `onCreate` and disposed in `onDestroy`; `HostSurface` paints a surface by id. The emulator reaches the host machine's server at `10.0.2.2`.

## Host plugin

The lower-level `SurfaceModel` + `ExponentialSurface` take a `HostPlugin` (every member has a default; `ClosureHost` builds one from lambdas): icons painted under `LocalContentColor`, `onAction`, `onInput` (`Change` debounced with a revision, `Commit` on blur or IME Done), `openUrl`, `fontFamily`, `markdown`. A `Markdown` also asks four optional hooks: a `textLinks` segment's `chip` paints as an inline Chip, `imageSize(src)` sizes a block image before it loads, `onImagePress` makes block images pressable, and `attachment(href)` turns a paragraph that is one link into a video, audio or file block. Register theme fonts with `ExponentialUi.registerFont(family, FontFamily)`. Details in the [Compose library's README](https://github.com/Niach/exponential/blob/master/packages/exponential-ui-compose/README.md). `HostPlugin.markdownOptions` (`MarkdownOptions(hardBreaks, chat, selectable, streaming)`, also on `HostPolicy`) sets how Markdowns render: hard breaks, the chat rhythm, selection, a streamed prefix; a document of 24+ blocks composes only its visible blocks.

## Compiled in CI

`bun packages/exponential-ui/guides/check.ts compose` builds [guides/compose](https://github.com/Niach/exponential/blob/master/packages/exponential-ui/guides/compose) in an empty directory against locally published Maven artifacts.
