## Packages

Every package publishes together from one `eui-v*` tag.

| Package | Registry | What it is | Install |
|---|---|---|---|
| `@exponential_app/eui` | npm | The catalog, themes, TypeScript reducer, host API and conformance suite. | `npm install @exponential_app/eui` |
| `@exponential_app/eui-react` | npm | The React renderer and its shadcn primitive set, with a compiled stylesheet. | `npm install @exponential_app/eui-react` |
| `@exponential_app/eui-solid` | npm | The SolidJS renderer and the same primitives, with the same DOM and stylesheet as React. | `npm install @exponential_app/eui-solid` |
| `@exponential_app/eui-element` | npm | The custom element `<exponential-surface>`: the Solid painter inside a web component, with no framework in the page. | `npm install @exponential_app/eui-element` |
| `eui-core` | crates.io | The Rust core: reducer, themes, taffy layout, layers, lists. | `cargo add eui-core` |
| `exponential-ui-ffi` | bundled | The UniFFI facade. It ships inside the Swift and Kotlin artifacts. | nothing to install |
| `eui-gpui` | git | The gpui painter. It stays a git dependency until gpui itself is on crates.io. | a git dependency on `github.com/Niach/exponential` |
| `ExponentialUI` | SwiftPM | The SwiftUI painter (iOS 17, macOS 14), from `github.com/Niach/exponential-ui-swift`. | `.package(url: "https://github.com/Niach/exponential-ui-swift", from: "0.20.0")` |
| `at.exponential:eui-compose` | Maven Central | The Compose painter (minSdk 26), with `ui-compose-primitives`. | `implementation("at.exponential:eui-compose:0.20.0")` |
