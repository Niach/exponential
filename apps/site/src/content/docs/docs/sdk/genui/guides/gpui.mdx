## Install

`eui-core` and `eui-gpui` are the genUI module for gpui.

Two crates: `eui-core` (the core) and `eui-gpui` (the painter and host runtime), taken from the release tag. Your app links the same gpui as the painter: the exact `gpui-pre` snapshot and `gpui-component` release, copied from one tag (the [gpui revision policy](https://github.com/Niach/exponential/blob/master/apps/desktop/crates/eui-gpui/README.md)). gpui needs Rust 1.98.1: pin it in `rust-toolchain.toml`.

```toml
[dependencies]
eui-core = { git = "https://github.com/Niach/exponential", tag = "eui-v0.20.0" }
eui-gpui = { git = "https://github.com/Niach/exponential", tag = "eui-v0.20.0" }
gpui = { package = "gpui-pre", version = "=0.3.11" }
gpui-component = "=0.9.0"
```

## Paint a surface

The host is a gpui entity. `host.surface(id)` returns the surface's view once the agent has created it; it is full width and as tall as its content, so wrap it in your own scroller.

## Host plugin

Underneath, a `SurfaceView` takes a `HostPlugin` implementation: catalog icon names to SVG asset paths, font families, actions and input. Register the theme's fonts with the text system before the first frame, and extension natives with `register_painter`. Markdown asks four optional hooks: `text_links` segments may carry a `chip` (painted inline as a Chip), `image_size` reserves a block image's box, `on_image_press` makes it pressable (with `image_pressable`), and `attachment` turns a one-link paragraph into a video, audio or file block; with no answer a Markdown paints as before. Details in the [gpui painter's README](https://github.com/Niach/exponential/blob/master/apps/desktop/crates/eui-gpui/README.md). `HostPlugin::markdown_options` (`MarkdownOptions { hard_breaks, chat, selectable, streaming }`, also on `HostPolicy`) sets how Markdowns render; a document of 24+ blocks lays out only the blocks inside the clip, and a copy across a chip gives its label.
