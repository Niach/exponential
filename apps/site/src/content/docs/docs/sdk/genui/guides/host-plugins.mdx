## The plugin

A host plugin is what your app lends a surface: **functions** it may call, **sources** its data model may follow, and the **policy** that gates both. All three are plain options of `ExponentialHost`:

## Functions

A surface calls a function with `{"functionCall": {"call": "cart.add", "args": {…}}}` on an event. The catalog's {FUNCTION_COUNT} functions are built in; any other name is namespaced (`cart.add`), must be registered, and passes the gate first: **deny** wins, then **allow**, then **ask** (your `onFunctionCall` consent hook), then `default`. Patterns are exact names or prefixes ending in `*`. A function may be async; the button stays pending until it settles.

## Data bindings

`bindDataModel` points a path at a source URI, `<scheme>:<name>?k=v`. The host parses it and calls your resolver for the scheme, which emits values whenever it likes (a poll, a socket, a local store) and returns a cancel function. Each emit lands at the bound path, and the surface repaints.

## URL and media policy

`openUrl`, `Link`, `Button.href` and `Row.href` go through the URL policy: allowed schemes (default `https http mailto tel`; `schemes: ["https"]` for https only), an optional host allowlist, relative URLs against a base. Media rules add headers to matching image requests, for example an authorization header for your own API and nothing for anyone else's.

An optional `textLinks(text)` turns parts of a `Row` subtitle or a `Markdown`'s text (never its code, a link's label or a bare url) into tappable spans: it answers segments `[{text, href?}]` that concatenate back to the text (else the text stays plain), each href passes the same policy, and a tap opens through `openUrl` without pressing the Row. The renderer knows nothing of what the links mean.

A `Markdown` asks four more optional hooks, so it can paint an issue tracker's text: a `textLinks` segment may carry `chip: {kind, label, icon?}` (`issue`, `mention` or `entity`) to paint as an inline Chip that opens its href; `imageSize(src)` answers a block image's `{width, height}` so its box keeps the aspect before the picture loads; `onImagePress(src)` makes block images pressable (a lightbox); `attachment(href)` answers `{kind, name}` (`video`, `audio` or `file`) for a paragraph that is exactly one link, which then paints as the Video, AudioPlayer or file row look. Without them a Markdown paints as before.

Private hosts are denied by default, for links and media alike: `localhost`, `*.local`, loopback, link-local (the cloud metadata address included) and the private IPv4 and IPv6 ranges. A host opts names back in with `allowPrivate: ["localhost"]` (a dev setup) or `["*"]`; a `hosts` allowlist alone leaves them denied. The check is on the literal address after URL normalization and resolves no names. The whole model, limits included, is on the [security page](/docs/sdk/genui/reference/security/).

The rules are the same on every platform: they are written once in [host.json](https://github.com/Niach/exponential/blob/master/packages/exponential-ui/catalog/host.json) and replayed from fixtures by every renderer. The Exponential web app is a host built on exactly this API: `harness.*` functions, an `exp:` source scheme over its synced data, a consent card for `ask`.
