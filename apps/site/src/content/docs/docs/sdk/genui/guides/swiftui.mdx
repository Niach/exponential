## Install

The `ExponentialUI` Swift package is the genUI module for SwiftUI.

The Swift package `ExponentialUI` (iOS 17, macOS 14) carries the painter and the Rust core as an xcframework, so your app builds no Rust. It is a SwiftPM dependency on `github.com/Niach/exponential-ui-swift`, whose tag `0.21.0` pins the xcframework of that release by checksum:

```swift
dependencies: [
    .package(url: "https://github.com/Niach/exponential-ui-swift", from: "0.21.0"),
],
targets: [
    .executableTarget(name: "App", dependencies: [.product(name: "ExponentialUI", package: "exponential-ui-swift")]),
]
```

The guide's own manifest builds the monorepo's package by path, so CI checks it without a download:

## Host plugin

For lower-level use, `SurfaceModel` + `ExponentialSurface` take a `HostPlugin`; every method has a default and `ClosureHost` builds one from closures:

- `icon(name, size)`: the catalog's icon names to your views.
- `onAction` gets every A2UI action. `onInput` gets text edits (debounced `change` with a revision, `commit` on blur or Return).
- `openUrl`, `textLinks`, `resolveUrl`, `fontFamily`, `markdown`.
- Markdown hooks, all optional: a `textLinks` segment's `chip` paints an inline Chip, `imageSize(src)` reserves an image's box before it loads, `onImagePress` makes block images pressable, and `attachment(href)` turns a one-link paragraph into a video, audio or file block. `HostPolicy` takes the same four as closures.
- Markdown options: `HostPlugin.markdownOptions` (`MarkdownOptions(hardBreaks:chat:selectable:streaming:)`, also on `HostPolicy`) sets hard breaks, the chat rhythm, selection and a streamed prefix; the measurer reads the same.

Register the font files a theme names with `ExponentialUI.registerFont(at:)`; switch themes with `ThemeHandle.load(json:)` and `setTheme`. Details in the [Swift package's README](https://github.com/Niach/exponential/blob/master/packages/exponential-ui-swift/README.md).
