## Install

These npm packages are the genUI module.

Two packages: `@exponential_app/eui` (the catalog, themes, reducer and host runtime) and `@exponential_app/eui-element` (the custom element `<exponential-surface>`). The page needs no framework and Vite needs no framework plugin; the element brings the Solid painter and its own styles.

```sh
npm install @exponential_app/eui @exponential_app/eui-element
```

## Paint a surface

Importing `@exponential_app/eui-element/define` registers the element. Its attributes are the surface's options (`theme`, `mode`, `density`, `locale`, `direction`, `width`, `surface-id`); the host box is `display: contents`, so the surface root is the box.

<GuideFile path="element/index.html" />

`apply(message)` takes A2UI v0.9 server messages; the element keeps the tree and the data model.

<GuideFile path="element/src/main.ts" />

Everything the user does arrives as a bubbling `CustomEvent`: `xui-action`, `xui-input` and `xui-upload` (`detail.waitUntil(promise)` keeps the control pending), `xui-function-call` (`detail.respond(value)`), `xui-open-url` (cancelable), `xui-ready`, `xui-status`, `xui-paint-error`. The DOM, the compiled stylesheet and the themes are the React renderer's, checked case by case in headless Chromium (DOM, computed styles, frames and pixels).

## With a host

`src` builds an `ExponentialHost` on the matching transport (`transport` = `jsonl`, `sse` or `ws`; `ws:` URLs pick WebSocket), connects when the element is attached and closes when it is removed; `post` is where actions go.

```html
<exponential-surface src="/a2ui.jsonl" post="/action" surface-id="main" theme="orange"></exponential-surface>
```

Or hand it your own host, a theme JSON and a host plugin as properties:

```ts
el.host = new ExponentialHost({ transport: new JsonlStreamTransport({ url: "/a2ui.jsonl", postUrl: "/action" }) })
el.theme = brandJson
el.plugin = { icons: iconsFromSvg((name) => svgFor(name)), openUrl: (url) => window.open(url) }
```

Extensions use `defineElementExtension`: a painter is a plain function from a context (props, theme, mode, `applyRootProps`, `children()`) to an `Element`, run again when they change. More in the [web component's README](https://github.com/Niach/exponential/blob/master/packages/exponential-ui-element/README.md).

## A surface in TypeScript

`defineSurface` from `@exponential_app/eui` works unchanged in a plain Vite project: the typed tree becomes the same messages an agent sends, and `apply()` on the element takes them. The file compiles under this project's tsconfig and runs under Node, with nothing element-specific in it. The DSL is the one from [Write a surface in TypeScript](/docs/sdk/genui/guides/define/); the second file paints it with `<exponential-surface>`.
