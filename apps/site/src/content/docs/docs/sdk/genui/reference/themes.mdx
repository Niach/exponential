## Tokens

A theme defines {tokenCount} tokens in {Object.keys(themesDoc.tokens).length} groups. A surface references them as `$<group>.<name>` (for example `$color.background`, `$spacing.lg`). Colours and shadows carry one value per mode. The tables list each built-in's values, generated into [`docs/themes.generated.json`](https://github.com/Niach/exponential/blob/master/packages/exponential-ui/docs/themes.generated.json).
