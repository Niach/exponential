## What is measured

The same {manifest.scenarios.length} scenarios run through every renderer, from one set of fixtures ([`scenarios/`](https://github.com/Niach/exponential/blob/master/packages/exponential-ui-bench/scenarios)). Every timing is wall time on the main thread for one *pass*, and each renderer defines its pass differently. Compare a renderer with itself across scenarios first, and renderers with each other only where the column says the same thing:

<BenchRenderers />

Counts (nodes, measure calls, facade calls, bytes) come from counters that live behind a debug flag in each renderer and cost nothing in a release build; memory is the process footprint after the scenario. A renderer that cannot measure an optional metric leaves it out.

## Run it, the ratchet

One command runs every runner the machine can (React, Solid and the web component in headless Chromium, the Rust core, gpui on Linux, SwiftUI on macOS and the iPhone Simulator, Compose on the JVM, and an attached iPhone or Android device when there is one), merges the fragments into `results/<machine>.json` and prints the ratchet's verdicts:

```sh
bun run --filter @exponential_app/eui-bench bench                 # everything this machine can run
bun run --filter @exponential_app/eui-bench bench -- --renderers react,solid --scenario list-100k --repeat 5
bun run --filter @exponential_app/eui-bench machine               # the id results are filed under
```

CI ([`exponential-ui.yml`](https://github.com/Niach/exponential/blob/master/.github/workflows/exponential-ui.yml)) runs each runner in its renderer's job and ratchets every fragment against [`budgets.json`](https://github.com/Niach/exponential/blob/master/packages/exponential-ui-bench/budgets.json):

- a metric worse than its budget fails the build;
- a count that got better fails too, until its budget is lowered in the same change;
- a timing far under its budget prints a warning asking to lower it.

A machine without budgets is only reported, and nothing gates on it: after a green run, record it from the artifacts.

```sh
bun run --filter @exponential_app/eui-bench ratchet .bench/*.json           # the verdicts
bun run --filter @exponential_app/eui-bench ratchet .bench/*.json --write   # timings × headroom, counts exact
```
