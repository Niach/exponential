## First login

Log out and pick **Exponential** in the login screen's session menu.

![Exponential Desktop on Ubuntu 26.04: the menu under the panel](/desktop/vm-menu.webp)
 **Exponential (safe mode)** starts with the factory settings and leaves your configuration untouched.

Updates arrive through your package manager. A running session keeps running; the new version starts at the next login. `exponential-repo` keeps the repository entry and key current.

## Check the machine

```sh
exponential-compositor doctor
```

Settings shows the same checks under **About**:

![Settings, About: the system check on Ubuntu 26.04 in a VM](/desktop/vm-settings-about.webp)

It runs from any desktop and checks the GPU and its render node, the displays, the seat, what EGL renders with, the keyboard layout, Xwayland and its version, and on NVIDIA that `nvidia-drm.modeset` is on, the driver's GBM library is installed and the driver has explicit sync.

<Aside title="NVIDIA">
  The session needs `nvidia-drm.modeset=1` (the driver's default from 560 on) and the driver's GBM library (Ubuntu, Mint: `libnvidia-egl-gbm1`; Arch: `egl-gbm`). Driver 555 or newer has explicit sync, so X11 games don't flicker.
</Aside>

## If it does not start

The screen says why and what happens next. A crash restarts the compositor; three quick crashes in a row bring the session back in safe mode. **Ctrl+Alt+F3** gives a text login; `journalctl --user -b` has the session's logs.
