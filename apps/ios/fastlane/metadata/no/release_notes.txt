- Runs: arbeidsflyter er borte, en kjøring planlegger og deler opp arbeidet sitt selv og starter oppfølgingskjøringer på egen hånd
- Blokkerte issues: når du starter et, får du valget Cancel, Start anyway eller Stacked PR, som bygger hele rekken av pull requests nedenfra og opp
- Sammenslåing: Merge på en stablet pull request spør om Merge stack eller Merge this pull request
- Arbeidsskjerm: velgere, bruksarket og filarket åpnes ved første trykk
- Run-fanen: transkripsjonen ruller inn under skrivefeltet, så de siste linjene alltid kan nås
