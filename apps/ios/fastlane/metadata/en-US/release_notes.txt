Everything since 0.14.0:

- Live coding sessions stay connected through network changes and app switches, and recover on their own when they drop
- Toggles and the Actions list got a cleaner look
- Start a chat with an agent straight from the Agents tab
- Pick a default machine and every Start coding dialog preselects it
- Live sessions keep streaming while you move around the app, and steering drafts survive reconnects
- No more notifications about your own pull requests
- Answer agent permission prompts from your phone instead of walking back to the machine
- Attach screenshots to a live coding session, and start coding on several issues at once
- Sessions show as paused while their machine is offline, and resume from anywhere
- Give an action a schedule or a trigger and one of your machines runs it on its own
- Manage every machine from the app: rename it, share it with your team, tidy its worktrees
- Emoji picker, image and file attachments on comments, and a formatting rail in the editor
- Issue lists group by status with clearer headers, a refreshed look, and smoother create and select menus
- Type # to link an issue; references render as live status chips
- Assignee picker, archivable boards, and a getting-started checklist
- Connect your own GitHub repos and share them with the team
- Fixed being logged out on every relaunch, plus a wave of stability and performance fixes
