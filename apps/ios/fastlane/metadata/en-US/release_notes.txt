- Continue with email, or with a passkey: sign in with a 6-digit code mailed to you, or with Face ID or Touch ID; every option is one Continue list, and an unknown email simply becomes a new account
- Working ends when the agent does: the working indicator follows the agent's real turn instead of the connection, showing what it is doing with the elapsed time and tokens, and Stop sits in the session header
- Exponential tool cards: when the agent calls Exponential, the transcript shows a plain caption like Creating issue or Opened pull request, and a preview of the result once it is done
- Subagents by name: a subagent chip carries the task it was given, its rows summarize the tools it used, and a read-only Plan chip shows while the run is still planning
- Workflow card: a run with several agents renders as one card with its phases and the agents under it, and a session row carries a second line saying what the run is working on right now
- Accounts that tell the truth: an agent account's health comes from a live usage probe, so a dead login reads Needs re-login instead of Signed in
- Devices is the repair page: sign an agent account in again there, or pick which signed-in account a machine uses
- Switch account mid-run: a Claude run that hits its limit can carry on with another account from the usage sheet or the rate-limit notice, as a new run linked to the old one
- The machine you tapped: a machine's play button opens the composer with that machine already selected, and the composer says why when a machine cannot take the run
- Back where you came from: leaving a session returns you to the issue, board or inbox you opened it from, and a run started by another run is nested under it
- Watch instead of Coding now: your own live run on an issue is a Watch pill in the issue's properties rather than a card of its own
- Chats and pins: a new chat offers suggestion chips to start from, and an issue, a session or an action can be pinned from its own screen
