- Workflows: a node whose run is live wears that run's own status dot, and a Running now strip above the waves opens each live run in one tap
- Workflows can run their contract, integration and high risk nodes on their own models (picked on the web or the desktop app), and editing a workflow on the phone keeps those picks
- The issue badge in a node's sheet opens the issue; node budgets and the paused node state are gone
- A workflow no longer stalls when a node's pull request is merged outside of it, and a node that fails to start is retried once instead of endlessly
