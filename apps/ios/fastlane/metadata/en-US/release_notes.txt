- One Work screen: an issue, its coding run and its changes are faces of one screen now, switched from the bar at the bottom, with Stop or Resume in the top-right corner
- One diff view: every diff reads the same, with line numbers, hidden unchanged lines you can open, and renames and binary files named instead of shown empty
- Stacked pull requests: start an issue on top of the one that blocks it, merge the chain with Merge stack, read the stack or batch badge on the work, and answer a question a nested run sends you
- Results from a run: a run that publishes screenshots gains a Results face, grouped by topic, one tile per platform, and tap a tile for the full picture
- Batch runs by name: a run covering several issues now reads EXP-874 +2 beside the first issue's title instead of Batch run
- Messages that land at once: a message typed while the agent works reaches it immediately and shows as sent until it is read, and Stop hands the text back to your composer
- GitHub, sorted out: connecting GitHub, adding a repository and setting a board's repository read and behave the same here as on the desktop, with errors shown where you are
- Queued messages: a message waiting for the agent shows in a bar above the composer, and Stop in a live session interrupts the running turn instead of getting lost on the way
- Quieter buttons and clearer pickers: only a screen's main action keeps a filled circle, and the agent picker carries the Claude Code or Codex mark while device menus lead with a laptop or server icon
- The Agent page holds your runs: past runs fold behind a count you can open, and with nothing running the prompt sits in the middle of the page instead of under the nav bar
- Sign in where the account is: signing in, choosing the active login and removing one now live on the account chips, and Add account in the Accounts header signs a new login in on a device
- Issue filters are gone: the filter button and its pills left the board and the inbox, search covers what they did, and grouping and the status bands stay
- Continue with email, or with a passkey: sign in with a 6-digit code mailed to you, or with Face ID or Touch ID; every option is one Continue list, and an unknown email simply becomes a new account
- Working ends when the agent does: the working indicator follows the agent's real turn instead of the connection, showing what it is doing with the elapsed time and tokens, and Stop sits in the session header
- Transcript cards: an Exponential call reads as a plain caption like Creating issue with a preview of its result, a subagent chip carries the task it was given, and a read-only Plan chip shows while the run is still planning
- Workflow card: a run with several agents renders as one card with its phases and the agents under it, and a session row carries a second line saying what the run is working on right now
- Accounts and repairs: an agent account's health comes from a live usage probe, so a dead login reads Needs re-login, and Devices lists each machine's logins with the right repair on a chip
- Switch account mid-run, and come back where you were: a Claude run at its limit can carry on with another account, and leaving a session returns you to the issue or board you opened it from
