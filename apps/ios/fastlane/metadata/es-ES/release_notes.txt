- Runs: los flujos de trabajo desaparecen, una ejecución planifica y reparte su propio trabajo y lanza por sí sola las ejecuciones de seguimiento
- Issues bloqueadas: al iniciar una se pregunta Cancel, Start anyway o Stacked PR, que construye toda la cadena de pull requests de abajo arriba
- Fusionar: Merge en una pull request apilada pregunta Merge stack o Merge this pull request
- Pantalla de trabajo: los selectores, la hoja de uso y la hoja de archivos se abren al primer toque
- Pestaña Run: la transcripción se desplaza bajo el cuadro de redacción, así que sus últimas líneas siguen accesibles
