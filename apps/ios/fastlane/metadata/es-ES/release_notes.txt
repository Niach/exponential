- Reviews: cada fila de pull request lleva un único control, Merge, o Merge stack en la base de un stack, y el pull request de un nodo de workflow indica que se fusiona a través del workflow
- Workflows: Open final PR aparece cuando el pull request final de un workflow se cerró, el registro de eventos está bajo el gráfico y un nodo elegido muestra solo sus propios eventos, y los estados fallidos o en espera se ven en ámbar
- Ejecuciones del agente: una ejecución que espera tu respuesta lleva un punto rojo, y una ejecución de workflow en otra cuenta indica cuál
- Iniciar un issue que ya tiene una ejecución activa lo avisa en lugar de iniciar una segunda
