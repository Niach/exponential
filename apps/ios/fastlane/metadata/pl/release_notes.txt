- Guide: Changes i Results issue to teraz jeden Guide; każda sekcja raportu agenta otwiera własny diff, a Show complete diff znajduje się na dole
- Uruchomienia: wątek uruchomienia czyta się tura po turze z Twoimi wiadomościami pomiędzy, a stosowy pull request scala się jednym przyciskiem Merge stack
- Edytor: przycisk + otwiera jedno menu (zaimplementuj issue, uruchom akcję, dodaj plik lub obraz do 50 MB, nakład pracy, subagenci, serwery MCP, obsługa komputera); sugestie to dyskretne wiersze pod polem
- Linki: link w odpowiedzi agenta lub w Guide prowadzący do uruchomienia lub issue otwiera się w aplikacji, pozostałe linki w przeglądarce w aplikacji, a gołe adresy URL można stuknąć
- Akcje: nieudane scalenie proponuje Fix merge conflicts, wbudowaną akcję, która wykonuje rebase, rozwiązuje konflikty i scala pull request
- Poprawki: Reviews podaje issue pull requesta, którego repozytorium jest połączone w innym zespole, tekst sesji już się nie nakłada, zniknął zdublowany przycisk, a runda dopracowania wyrównuje wiersze, odstępy i teksty w całej aplikacji
