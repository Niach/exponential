- Runs: workflowy zniknęły, uruchomienie samo planuje i dzieli swoją pracę oraz samo startuje kolejne uruchomienia
- Zablokowane issues: przy starcie pojawia się wybór Cancel, Start anyway lub Stacked PR, który buduje cały ciąg pull requestów od dołu do góry
- Scalanie: Merge na pull requeście ze stosu pyta o Merge stack lub Merge this pull request
- Ekran pracy: selektory, arkusz użycia i arkusz plików otwierają się przy pierwszym dotknięciu
- Karta Run: zapis przewija się pod polem pisania, więc jego ostatnie linie są zawsze dostępne
