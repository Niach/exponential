- Runs: workflowy sú preč, beh si sám naplánuje a rozdelí prácu a sám spúšťa nadväzujúce behy
- Blokované issues: pri spustení sa zobrazí voľba Cancel, Start anyway alebo Stacked PR, ktorá zostaví celý rad pull requestov zdola nahor
- Zlučovanie: Merge pri nadväzujúcom pull requeste ponúkne Merge stack alebo Merge this pull request
- Pracovná obrazovka: výbery, prehľad využitia a prehľad súborov sa otvoria hneď na prvé ťuknutie
- Karta Run: prepis sa posúva pod editor správ, takže jeho posledné riadky zostanú dostupné
