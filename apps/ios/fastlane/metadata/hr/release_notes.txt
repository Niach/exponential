- Runs: workflowi su uklonjeni, pokretanje samo planira i dijeli svoj posao te samo pokreće nastavna pokretanja
- Blokirani issues: pokretanje jednog nudi Cancel, Start anyway ili Stacked PR, koji gradi cijeli niz pull requestova odozdo prema gore
- Spajanje: Merge na složenom pull requestu nudi Merge stack ili Merge this pull request
- Radni zaslon: birači, list potrošnje i list datoteka otvaraju se na prvi dodir
- Kartica Run: zapis se pomiče ispod polja za pisanje, pa njegovi zadnji redci ostaju dostupni
