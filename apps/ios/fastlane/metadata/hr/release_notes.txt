- GitHub: jedna vođena stranica povezuje vaš GitHub račun, instalira aplikaciju i prikazuje repozitorije u koje možete pushati
- Povratne informacije: prijava iz widgeta je issue, prijavitelju odgovarate iz polja za komentare, a njegovi odgovori vraćaju se kao komentari
- Novi issue: stvaranje otvara cijelu stranicu sa svim svojstvima, koja se sprema kao skica dok pišete
- Navigacija: kartice Inbox, Devices, Reviews, Agent i Actions; Reviews, pokretanja, akcije i uređaji prikazuju sve vaše timove
- Pull requestovi: diff je prikaz Changes na issueu, Results se čita kao numerirani vodič, Merge je na donjoj traci
- Runs: oznaka agenta vrti se dok radi, narančasta čeka vas, zelena ima otvoren pull request, plava je gotova
- Zaslon issuea: naslov se pri pomicanju sklapa u zaglavlje, a sadržaj klizi ispod zamućenog ruba
- Pridruživanje timu: pozivnica nudi korak postavljanja uređaja ako još nemate uređaj
