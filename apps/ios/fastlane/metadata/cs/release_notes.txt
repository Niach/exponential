- Výběry: stav, řešitel, štítky, board i zbytek otevírají tentýž prohledávatelný list prostých řádků a vícenásobný výběr se pozná podle zvýraznění, ne podle kolečka
- Běhy agentů: seznam běžících běhů se vnořuje, běhy workflow stojí pod jedním řádkem, který workflow otevře, běhy stacku pod dalším, a šipka oba sbalí
- Workflows: obrazovka ztrácí blok nastavení, uzel říká svůj vlastní stav a otevírá se do Issue, Run a Changes a finální pull request se mergne odtud
- Nastavení stroje: list je přeuspořádaný a nová stránka „Workflow settings“ drží modely, se kterými nový workflow startuje
