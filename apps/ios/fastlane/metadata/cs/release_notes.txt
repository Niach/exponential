- Záhlaví vlákna: už nic neroluje, issues a sessions se při nedostatku místa složí do "+N" a pod-issues a hlubší sessions otevřete klepnutím
- Propojení issue: "+" vedle Conversation nabízí Link an issue a New issue
- Pod-sessions: otázky a plány pod-session se zobrazí v konverzaci vlákna a odpovíte na ně přímo tam
- Jedno pole pro psaní: vlákno, session i nový start sdílejí jedno pole, "Type / for commands", s obrázkem, souborem, # a emoji přímo v poli
- Možnosti během session: režim Plan se přepne okamžitě a úsilí, computer use a MCP servery platí od další zprávy
- Stav issue: propojené issue přejde do In progress a pull request ho posune do In review a po sloučení do Done
