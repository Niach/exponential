- Runs: workflowy jsou pryč, běh si sám naplánuje a rozdělí práci a sám spouští navazující běhy
- Blokované issues: při spuštění se zobrazí volba Cancel, Start anyway nebo Stacked PR, která sestaví celou řadu pull requestů odspodu nahoru
- Slučování: Merge u navazujícího pull requestu nabídne Merge stack nebo Merge this pull request
- Pracovní obrazovka: výběry, přehled využití a přehled souborů se otevřou hned na první klepnutí
- Karta Run: přepis se posouvá pod editor zpráv, takže jeho poslední řádky zůstanou dostupné
