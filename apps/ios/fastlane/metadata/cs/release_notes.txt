- Reviews: každý řádek pull requestu má jediný ovládací prvek, Merge, nebo Merge stack na spodku stacku, a pull request uzlu workflow uvádí, že se mergne přes workflow
- Workflows: Open final PR se objeví, když byl finální pull request workflow zavřen, log událostí je pod grafem a vybraný uzel ukazuje jen své vlastní události, a stavy selhání nebo čekání jsou jantarové
- Běhy agentů: běh, který čeká na vaši odpověď, má červenou tečku, a běh workflow na jiném účtu uvádí, na kterém
- Spuštění issue, které už má živý běh, to oznámí místo spuštění druhého
