- Threads: cada trabalho é uma conversa, listada como Precisa de si, Em curso e Recentes, com cada sessão como cartão
- Agentes da equipa: adicione em Definições agentes que cuidam de um quadro a partir do seu próprio dispositivo e abrem uma thread para cada trabalho
- Threads partilhadas: uma thread num dispositivo partilhado com a equipa é visível para toda a equipa, que pode responder e pará-la
- As ações são prompts guardados, e fazer merge de um pull request já não termina uma sessão
