- Guide: as Changes e Results de uma issue são agora um único Guide; cada secção do relatório do agente abre o seu próprio diff, Show complete diff fica no fundo e Merge fica na barra inferior enquanto o pull request estiver aberto
- Execuções: uma execução abre como conversa com uma linha de estado (dispositivo, tempo decorrido, última ferramenta) e lê-se turno a turno com as suas mensagens pelo meio; Show work abre a transcrição completa, uma seta salta para a mensagem mais recente e a lista de tarefas mostra o progresso
- Execuções: o logótipo do agente roda enquanto trabalha, âmbar espera por si, verde tem um pull request aberto, azul terminou e uma execução mostra Working até o agente terminar mesmo
- Composição: o botão + abre um único menu (implementar uma issue, executar uma ação, adicionar um ficheiro ou imagem até 50 MB, esforço, subagentes, servidores MCP, Computer use); as sugestões são linhas discretas sob o campo
- Ligações: uma ligação para uma execução ou issue numa resposta do agente ou num Guide abre na app, as outras no navegador integrado, e os URL simples podem ser tocados
- Pilhas: uma issue bloqueada pode começar como Stacked PR, que constrói toda a sequência de pull requests de baixo para cima, e um pull request empilhado é integrado com um único controlo Merge stack
- Ações: as automatizações são agora acionadores na ação que executam, cada ação é uma página com prompt, acionadores e execuções, um merge falhado oferece Fix merge conflicts, Tidy up arruma um quadro e eliminar uma ação pede confirmação
- Navegação: a app abre na página Agent com os separadores Inbox, Devices, Reviews, Agent e Actions; Reviews, execuções, ações e dispositivos incluem todas as suas equipas, e Inbox, My issues e Drafts deslizam para o lado
- Reviews: um pull request de um chat ou de uma ação abre o seu Guide na app, e um pull request cujo repositório está ligado noutra equipa indica a sua issue
- Nova issue: criar uma issue abre uma página completa com todas as propriedades, guardada como rascunho enquanto escreve; uma issue criada a partir de um rascunho noutro dispositivo aparece aqui, e sair de um rascunho com conteúdo pergunta Create, Keep as draft ou Discard
- Issues: Start coding abre uma lista Ready to code quando falta algo, uma sub-issue indica a issue mãe e mostra o progresso com um anel, as relações agrupam-se em secções recolhíveis e o título recolhe para o cabeçalho ao deslizar
- GitHub: uma página guiada liga a sua conta GitHub, instala a app e lista os repositórios para onde pode fazer push
- Feedback: um envio do widget é uma issue; responda ao autor a partir do campo de comentários e as respostas dele voltam como comentários
- Conta: altere o seu email com um código, associe ou desassocie os acessos Google, Apple e OIDC desde que reste outra forma de entrar, e gira as passkeys
- Servidores MCP: ligue a sua conta uma vez na web a um servidor MCP da equipa, e cada execução que iniciar em qualquer máquina passa a usá-lo
- Dispositivos: o bloco de preparação diz o que falta a uma máquina, Computer use pode ser ativado por dispositivo e cada sessão de agente oferece Sign out
- Diálogos e avisos: cada confirmação e escolha usa o mesmo cartão, Return nunca escolhe uma resposta destrutiva e os avisos empilham-se, toque para expandir, deslize para dispensar
- Entrar numa equipa: o convite oferece o passo do dispositivo quando ainda não tem nenhum, e o registo com código por email pede o seu nome
- Correções: os quadros mostram um indicador até as issues chegarem, o texto da sessão já não se sobrepõe, um botão duplicado desapareceu, uma execução num repositório vazio arranca e uma ronda de polimento alinha linhas, espaçamentos e textos em toda a app
