- Reviews: cada linha de pull request tem um único controlo, Merge, ou Merge stack na base de uma stack, e o pull request de um nó de workflow indica que é integrado através do workflow
- Workflows: Open final PR aparece quando o pull request final de um workflow foi fechado, o registo de eventos fica por baixo do grafo e um nó escolhido mostra só os seus próprios eventos, e os estados falhados ou em espera aparecem em âmbar
- Execuções do agente: uma execução à espera da sua resposta tem um ponto vermelho, e uma execução de workflow noutra conta indica qual
- Iniciar um issue que já tem uma execução ativa avisa disso em vez de iniciar uma segunda
