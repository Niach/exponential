- Runs: os fluxos de trabalho desapareceram, uma execução planeia e divide o seu próprio trabalho e inicia sozinha as execuções seguintes
- Issues bloqueados: ao iniciar um, surge Cancel, Start anyway ou Stacked PR, que constrói toda a cadeia de pull requests de baixo para cima
- Integração: Merge num pull request empilhado pergunta Merge stack ou Merge this pull request
- Ecrã de trabalho: os seletores, a folha de utilização e a folha de ficheiros abrem ao primeiro toque
- Separador Run: a transcrição desliza por baixo da caixa de escrita, por isso as últimas linhas continuam acessíveis
