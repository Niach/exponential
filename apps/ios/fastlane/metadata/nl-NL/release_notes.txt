- Video en audio in beschrijvingen en reacties: voeg een clip toe en hij speelt daar meteen af, met een voorbeeldafbeelding en zijn lengte; wat je uploadt wordt eerst naar 720p omgezet
- GitHub-accounts: de teaminstellingen tonen elk gekoppeld account met een "Configure"-link, en "Connect another account" opent de accountkeuze van GitHub zelf, zodat ook een tweede organisatie geïnstalleerd kan worden
- Repository toevoegen: de kiezer zegt waarom een repository ontbreekt, verwijst naar de GitHub-instellingen van elk account en neemt een repository op naam
- Kortere lijst met eerdere runs: een beëindigde run toont de machine en de tijd, zonder de naam van de agent en de reden van het einde
- De stip van een lopende sessie zit nu op de Chat-knop in de onderste balk, die op elk tabblad verschijnt; Devices houdt alleen de inlogwaarschuwing
- Het veld noemt altijd de machine waarop een run start en opent alleen een menu als er meer dan één is
- De limietbanner verdwijnt vanzelf zodra de resettijd voorbij is, en een gewone verbruikswaarschuwing wordt nooit als limiet getoond
- Deel een machine met meerdere teams: het apparaatblad heeft één schakelaar per team in plaats van één enkele keuze
- Details in het veld: "Plan" is een schakelaar, een gekozen issue of actie haal je weg met zijn eigen sluitknop, en de onderste balk van een board voegt chat en nieuwe issue samen in één capsule
- Pins: zet een issue, een sessie of een actie vast vanuit zijn menu, dan staat hij in de sectie "Pinned" bovenaan de boardkiezer
- Accounts op de pagina Devices: één regel per agentaccount met zijn verbruiksbalken en een chip per machine, dezelfde sectie die web en desktop al hebben
- Eén invoerveld voor alles: het veld op de "Agent"-pagina start alles, met issues of een actie bovenaan en machine, agent, model en planmodus eronder; het "Start coding"-blad is weg
- Elke afspeelknop komt daar uit: "Start coding" op een issue, de selectiebalk, "Run" van een actie en "Fix merge conflicts" openen het veld met de juiste selectie al gemaakt
- Instructies bij een start: wat je naast de gekozen issues of actie typt, bereikt de run als extra instructies; bij een chat is het de prompt
- Afbeeldingen bij een start: voeg tot vier afbeeldingen toe aan het veld, de machine heeft ze voor de eerste beurt
- Acties houden alleen keuzes over: een actie vraagt om een repository, board, pull request of icoon; de vrije tekst komt uit het veld, met de hint van de actie als tijdelijke tekst
- Sessies naast het veld: de "Agent"-pagina toont je lopende en eerdere runs naast de prompt, en een run die door een andere run is gestart staat eronder genest
- Antwoorden in de kaart: een plan of een vraag beantwoord je in de kaart zelf, met een veld erin als je liever schrijft dan kiest; het stuurveld gaat zolang opzij
- Agentberichten: een agent kan je team een melding sturen via MCP; die komt binnen als push en als eigen regel in de Inbox
- Limieten die kloppen: een verbruikswaarschuwing markeert een run niet meer als gelimiteerd, en bij een echte limiet beschrijven het venster en de resettijd hetzelfde
