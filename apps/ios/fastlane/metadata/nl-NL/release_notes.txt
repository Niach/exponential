- Sturen: wissel tijdens de lopende sessie tussen "Plan" en "Build"; model en inspanning kies je één keer bij de start, en context- en verbruikswaarden werken bij zodra de run ze meldt
- Eerdere runs: afgeronde sessies staan per apparaat in de lijst met "Resume", zodat een beëindigde run weer opgepakt kan worden
- Chat zonder repository: een chat vanuit het "Start coding"-blad heeft geen repository meer nodig en draait in een tijdelijke map met alleen de Exponential-tools
- Agentkiezer: is een agent niet klaar op een apparaat, dan zegt de kiezer dat en blokkeert hij de start tot je daar de doctor draait
- Stuurfeed: issue-identifiers als #EXP-12 worden chips waarop je kunt tikken, en agentcommando's verschijnen als commandolabels
- Relaties tussen issues: koppel issues als bovenliggend, sub-issue, blokkeert, geblokkeerd door, duplicaat of gerelateerd vanuit het eigenschappenblad; #EXP-12 typen in een beschrijving of reactie koppelt de twee issues vanzelf
- Reacties in threads: reageer onder een reactie vanuit het vastgezette invoerveld; threads blijven één niveau diep, en een reactie die een agent via MCP plaatste, zegt dat in zijn koptekst
- Een begeleide eerste start: een team aanmaken loodst je langs het eerste board, het uitnodigen van teamgenoten en het instellen van apparaten, in dezelfde volgorde als web en desktop
- Teaminstellingen: eigenaren kunnen uitnodigingslinks maken in de sectie "Members"
- Merge vanuit actie- en chatruns: een run die een pull request heeft geopend, toont "Merge" in zijn stuurweergave, en Reviews toont die pull requests onder "Agent runs"
- Grotere afbeeldingen in reacties: afbeeldingen bij een reactie tonen op volle breedte en openen bij een tik de viewer
- Een rustiger activiteitenfeed: gebeurtenissen staan als één gedempte regel met een tijd, reacties zitten in één kaart
- De knop "Subscribe" is weg: je volgt een issue automatisch wanneer je het aanmaakt, erop reageert, het toegewezen krijgt of erin genoemd wordt
- Sturen: de contextbalk overlapt het transcript niet meer
- Sessies blijven op je eigen apparaat: transcripten staan op het apparaat dat ze draaide, nooit op de server; eerdere runs open je vanuit Devices, Chat en Automations en ze worden van dat apparaat opgehaald zodra het online is
- Subagentgesprekken: de beurten van een subagent staan in een eigen weergave, en tekst van de agent valt niet meer midden in een zin uiteen over losse regels
- Een run die stil valt, zegt het: de sessie laat zien wanneer de agent geen voortgang meer meldt
- Agent op afstand aanmelden: plak de code uit de loginlink van een agent in de instellingen van het apparaat en rond het aanmelden af vanaf je telefoon
- "Start coding": één blad voor issues, acties en chat met overal dezelfde opties
