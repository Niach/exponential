- Workflows: een knoop waarvan de run leeft draagt de statusstip van die run zelf, en een Running now-strook boven de golven opent elke lopende run met één tik
- Workflows kunnen hun contract-, integratie- en hoogrisicoknopen op eigen modellen draaien (gekozen op het web of in de desktop-app), en een workflow op de telefoon bewerken houdt die keuzes vast
- Het issue-merk in het paneel van een knoop opent de issue; knoopbudgetten en de gepauzeerde knooptoestand zijn weg
- Een workflow loopt niet meer vast wanneer de pull request van een knoop erbuiten wordt samengevoegd, en een knoop die niet wil starten wordt één keer opnieuw geprobeerd in plaats van eindeloos
