- Reviews: elke pull request-rij heeft één knop, Merge, of Merge stack onderaan een stack, en de pull request van een workflow-node meldt dat hij via de workflow gemerged wordt
- Workflows: Open final PR verschijnt wanneer de laatste pull request van een workflow gesloten is, het gebeurtenislogboek staat onder de graaf en een gekozen node toont alleen zijn eigen gebeurtenissen, en mislukte of wachtende statussen kleuren amber
- Agentruns: een run die op jouw antwoord wacht krijgt een rode stip, en een workflowrun op een ander account zegt welk
- Een issue starten dat al een actieve run heeft, meldt dat in plaats van een tweede te starten
