- Eén invoerveld voor alles: het veld op de "Agent"-pagina start alles, met issues of een actie bovenaan en machine, agent, model en planmodus eronder; het "Start coding"-blad is weg
- Elke afspeelknop komt daar uit: "Start coding" op een issue, de selectiebalk, "Run" van een actie en "Fix merge conflicts" openen het veld met de juiste selectie al gemaakt
- Instructies bij een start: wat je naast de gekozen issues of actie typt, bereikt de run als extra instructies; bij een chat is het de prompt
- Afbeeldingen bij een start: voeg tot vier afbeeldingen toe aan het veld, de machine heeft ze voor de eerste beurt
- Acties houden alleen keuzes over: een actie vraagt om een repository, board, pull request of icoon; de vrije tekst komt uit het veld, met de hint van de actie als tijdelijke tekst
- Sessies naast het veld: de "Agent"-pagina toont je lopende en eerdere runs naast de prompt, en een run die door een andere run is gestart staat eronder genest
- Antwoorden in de kaart: een plan of een vraag beantwoord je in de kaart zelf, met een veld erin als je liever schrijft dan kiest; het stuurveld gaat zolang opzij
- Agentberichten: een agent kan je team een melding sturen via MCP; die komt binnen als push en als eigen regel in de Inbox
- Limieten die kloppen: een verbruikswaarschuwing markeert een run niet meer als gelimiteerd, en bij een echte limiet beschrijven het venster en de resettijd hetzelfde
- Gelimiteerd, niet vastgelopen: als een agent halverwege zijn quotum opgebruikt, wordt de sessie als gelimiteerd gemarkeerd met het tijdstip van de reset, en blijft ze actief en bestuurbaar in plaats van stil te vallen
- Stuurveld: het sessieveld neemt @ voor teamgenoten, # voor issues en : voor emoji, dezelfde drie als het reactievak
- Bewerkingen inline: de diff van een bewerking staat onder zijn rij in het transcript, ingeklapt tot je erop tikt
- Toolgroepen die zeggen wat er gebeurde: een ingeklapte reeks toolaanroepen leest als "4 opdrachten uitgevoerd, 2 bestanden bewerkt, 1 mislukt" in plaats van een telling
- Een kansloze start wordt geweigerd: starten op een machine waarvan de agent al geen quotum meer heeft, meldt dat en noemt het resettijdstip
- Gebruiksbalken voor een tweede agentaccount op dezelfde machine
- Agentkiezer: is een agent niet klaar op een apparaat, dan zegt de kiezer dat en blokkeert hij de start tot je daar de doctor draait
- Stuurfeed: issue-identifiers als #EXP-12 worden chips waarop je kunt tikken, en agentcommando's verschijnen als commandolabels
- Relaties tussen issues: koppel issues als bovenliggend, sub-issue, blokkeert, geblokkeerd door, duplicaat of gerelateerd vanuit het eigenschappenblad; #EXP-12 typen in een beschrijving of reactie koppelt de twee issues vanzelf
- Reacties in threads: reageer onder een reactie vanuit het vastgezette invoerveld; threads blijven één niveau diep, en een reactie die een agent via MCP plaatste, zegt dat in zijn koptekst
- Een begeleide eerste start: een team aanmaken loodst je langs het eerste board, het uitnodigen van teamgenoten en het instellen van apparaten, in dezelfde volgorde als web en desktop
- Merge vanuit actie- en chatruns: een run die een pull request heeft geopend, toont "Merge" in zijn stuurweergave, en Reviews toont die pull requests onder "Agent runs"
- Sessies blijven op je eigen apparaat: transcripten staan op het apparaat dat ze draaide, nooit op de server; eerdere runs open je vanuit Devices, Chat en Automations en ze worden van dat apparaat opgehaald zodra het online is
