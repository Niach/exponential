- Runs: arbetsflöden är borta, en körning planerar och delar upp sitt arbete själv och startar uppföljande körningar på egen hand
- Blockerade issues: när du startar ett får du välja Cancel, Start anyway eller Stacked PR, som bygger hela raden av pull requests nerifrån och upp
- Sammanslagning: Merge på en staplad pull request frågar Merge stack eller Merge this pull request
- Arbetsvy: väljare, användningsbladet och filbladet öppnas vid första trycket
- Fliken Run: transkriptet rullar in under skrivfältet, så dess sista rader går att nå
