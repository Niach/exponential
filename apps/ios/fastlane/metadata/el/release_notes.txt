- Οθόνη εργασίας: τα Issue, Εκτέλεση, Αλλαγές και Αποτελέσματα είναι καρτέλες στην κεφαλίδα που αλλάζουν με σάρωση, με το Merge δίπλα όσο το pull request είναι ανοιχτό
- Settings > Account: αλλάξτε το email σας με έναν κωδικό, συνδέστε ή αποσυνδέστε λογαριασμούς Google, Apple και OIDC και διαχειριστείτε τα passkeys
- Κατά τη συγχώνευση ενός στοιβαγμένου pull request, η εφαρμογή ρωτά αν θα συγχωνευθεί όλη η στοίβα ή μόνο αυτό το pull request
- Αποτελέσματα: η αναφορά μιας εκτέλεσης εμφανίζεται δίπλα στα στιγμιότυπα οθόνης, τα μακριά στιγμιότυπα ανοίγουν σε προβολή με κύλιση και μια ειδοποίηση μπορεί να ανοίξει απευθείας τα Αποτελέσματα
- Τα συνημμένα Markdown ανοίγουν σε προεπισκόπηση μέσα στην εφαρμογή
- Ειδοποιήσεις: ένα ενιαίο στυλ με στοίβαξη παντού, πατήστε για ανάπτυξη, σαρώστε για απόρριψη
- Tidy up: μια ενσωματωμένη ενέργεια για τακτοποίηση των boards, με ταιριαστά εικονίδια για στοίβες, παρτίδες και workflows
- Τα sub-issues που δημιουργούνται με συνημμένο δεν αφήνουν πια πίσω τους πρόχειρο
