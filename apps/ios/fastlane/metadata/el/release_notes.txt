- Runs: τα workflows καταργήθηκαν, μια εκτέλεση σχεδιάζει και μοιράζει μόνη της τη δουλειά της και ξεκινά μόνη της επόμενες εκτελέσεις
- Μπλοκαρισμένα issues: η έναρξη ενός ρωτά Cancel, Start anyway ή Stacked PR, που χτίζει όλη τη σειρά των pull requests από κάτω προς τα πάνω
- Συγχώνευση: το Merge σε ένα stacked pull request ρωτά Merge stack ή Merge this pull request
- Οθόνη εργασίας: οι επιλογείς, το φύλλο χρήσης και το φύλλο αρχείων ανοίγουν με το πρώτο πάτημα
- Καρτέλα Run: το ιστορικό κυλά κάτω από το πεδίο γραφής, ώστε οι τελευταίες γραμμές του να μένουν προσβάσιμες
