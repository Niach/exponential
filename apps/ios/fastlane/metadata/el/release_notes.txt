- Νήματα: ένα νήμα είναι μία οθόνη σε κάθε συσκευή, με εργασίες, συνεδρίες και Guide σε μία λωρίδα, και το Home έχει το πεδίο γραφής κάτω, πάνω στην αυγή
- Τίτλοι: ένα νήμα παίρνει το όνομα της εργασίας του, όπως Implement EXP-12 ή Run Triage, ώστε κάθε λίστα να διαβάζεται ίδια σε κινητό, web και υπολογιστή
- Ερωτήσεις: οι επιλογές ενός πράκτορα μπορούν να έχουν σύντομη περιγραφή και κάθε ερώτηση έχει μια γραμμή για τη δική σας απάντηση
- Guide: μια εικόνα ανοίγει δίπλα στις σημειώσεις της, με βέλη προς την επόμενη, και όσοι προστέθηκαν στην ομάδα χωρίς πρόσκληση εμφανίζονται ως Not invited
- Λογαριασμοί: μια συνεδρία που φτάνει το όριο χρήσης της μπορεί να μεταβεί σε άλλον συνδεδεμένο λογαριασμό και να συνεχίσει
