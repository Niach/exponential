- Reviews: κάθε γραμμή pull request έχει ένα μόνο χειριστήριο, Merge, ή Merge stack στη βάση ενός stack, και το pull request ενός κόμβου workflow αναφέρει ότι γίνεται merge μέσω του workflow
- Workflows: το Open final PR εμφανίζεται όταν το τελικό pull request ενός workflow έκλεισε, το αρχείο συμβάντων βρίσκεται κάτω από το γράφημα και ένας επιλεγμένος κόμβος δείχνει μόνο τα δικά του συμβάντα, και οι καταστάσεις αποτυχίας ή αναμονής εμφανίζονται κεχριμπαρένιες
- Εκτελέσεις agent: μια εκτέλεση που περιμένει την απάντησή σας έχει κόκκινη τελεία, και μια εκτέλεση workflow σε άλλο λογαριασμό δείχνει ποιον
- Η εκκίνηση ενός issue που έχει ήδη ζωντανή εκτέλεση το αναφέρει αντί να ξεκινήσει δεύτερη
