- Εκτελέσεις: μια εκτέλεση ανοίγει ως νήμα με γραμμή κατάστασης (Building on <device>, χρόνος που πέρασε, τελευταία γραμμή εργαλείου) και τα αποτελέσματά της μέσα σε αυτό· το Show work ανοίγει την πλήρη απομαγνητοφώνηση
- Πρόχειρα: ένα issue που δημιουργήθηκε από πρόχειρο σε άλλη συσκευή ανοίγει εδώ ως issue, και ένα πρόχειρο που απορρίφθηκε κλείνει παντού
- Ενέργειες: η διαγραφή μιας ενέργειας ζητά πρώτα επιβεβαίωση, στην κοινή κάρτα ειδοποίησης
- Συσκευές: το Codex δεν χρειάζεται πλέον εγκατάσταση CLI· το IDE το κατεβάζει στην πρώτη σύνδεση
- Διορθώσεις: η συγχώνευση pull request ενός agent χωρίς issue λειτουργεί, και οι εικόνες αποτελεσμάτων ανεβαίνουν αξιόπιστα
