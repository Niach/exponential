- Σχέσεις θεμάτων: συνδέστε θέματα ως γονικό, υποθέμα, εμποδίζει, εμποδίζεται από, διπλότυπο ή σχετικό από το φύλλο ιδιοτήτων· γράφοντας #EXP-12 σε μια περιγραφή ή ένα σχόλιο, τα δύο θέματα συνδέονται από μόνα τους
- Νήματα σχολίων: απαντήστε κάτω από ένα σχόλιο μέσα από τον αγκιστρωμένο συντάκτη· τα νήματα μένουν ένα επίπεδο βαθιά, και ένα σχόλιο που έγραψε ένας agent μέσω MCP το δηλώνει στην κεφαλίδα του
- Καθοδηγούμενη πρώτη εκκίνηση: η δημιουργία μιας ομάδας σας περνά από το πρώτο board, τις προσκλήσεις συνεργατών και τη ρύθμιση συσκευών, με την ίδια σειρά όπως στο web και στον υπολογιστή
- Ρυθμίσεις ομάδας: οι ιδιοκτήτες μπορούν να δημιουργούν συνδέσμους πρόσκλησης από την ενότητα «Members»
- Merge από εκτελέσεις ενεργειών και chat: μια εκτέλεση που άνοιξε ένα pull request δείχνει το «Merge» στην προβολή καθοδήγησής της, και το Reviews εμφανίζει αυτά τα pull request κάτω από το «Agent runs»
- Μεγαλύτερες εικόνες σχολίων: οι εικόνες που επισυνάπτονται σε ένα σχόλιο εμφανίζονται σε πλήρες πλάτος και ανοίγουν στο πρόγραμμα προβολής με ένα πάτημα
- Πιο ήσυχη ροή δραστηριότητας: τα συμβάντα διαβάζονται ως μία διακριτική γραμμή με ώρα, τα σχόλια κάθονται σε μία κάρτα
- Το κουμπί «Subscribe» αποσύρθηκε: ακολουθείτε αυτόματα ένα θέμα όταν το δημιουργείτε, το σχολιάζετε, σας ανατεθεί ή σας αναφέρουν
- Καθοδήγηση: η μπάρα context δεν καλύπτει πια τη μεταγραφή
