- Guide: τα Changes και Results ενός issue είναι πλέον ένας Guide· κάθε ενότητα της αναφοράς του agent ανοίγει το δικό της diff, και το Show complete diff βρίσκεται στο κάτω μέρος
- Εκτελέσεις: το νήμα της εκτέλεσης διαβάζεται γύρο προς γύρο με τα δικά σας μηνύματα ενδιάμεσα, και ένα στοιβαγμένο pull request συγχωνεύεται με ένα μόνο στοιχείο Merge stack
- Επεξεργαστής: το κουμπί + ανοίγει ένα μενού (υλοποίηση issue, εκτέλεση ενέργειας, προσθήκη αρχείου ή εικόνας έως 50 MB, προσπάθεια, subagents, διακομιστές MCP, χρήση υπολογιστή)· οι προτάσεις είναι διακριτικές γραμμές κάτω από το πεδίο
- Σύνδεσμοι: ένας σύνδεσμος σε απάντηση agent ή στον Guide που δείχνει σε εκτέλεση ή issue ανοίγει στην εφαρμογή, οι άλλοι σύνδεσμοι στο πρόγραμμα περιήγησης της εφαρμογής, και τα σκέτα URL πατιούνται
- Ενέργειες: μια αποτυχημένη συγχώνευση προτείνει το Fix merge conflicts, μια ενσωματωμένη ενέργεια που κάνει rebase, επιλύει τις συγκρούσεις και συγχωνεύει το pull request
- Διορθώσεις: το Reviews δείχνει το issue ενός pull request του οποίου το αποθετήριο είναι συνδεδεμένο σε άλλη ομάδα, το κείμενο της συνεδρίας δεν επικαλύπτεται πια, ένα διπλό κουμπί αφαιρέθηκε, και ένας γύρος βελτιώσεων ευθυγραμμίζει γραμμές, αποστάσεις και κείμενα σε όλη την εφαρμογή
