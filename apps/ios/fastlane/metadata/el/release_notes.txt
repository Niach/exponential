- Κλήση στον agent (beta): καλέστε τον agent της φωνητικής σας συσκευής από το iPhone, το web ή την εφαρμογή υπολογιστή και μιλήστε του χωρίς χέρια
- Λέξη αφύπνισης (beta): πείτε τη φράση αφύπνισης κοντά στη φωνητική σας συσκευή για να μιλήσετε, χωρίς συντόμευση
- Εκφωνούμενες απαντήσεις (beta): οι απαντήσεις διαβάζονται δυνατά στα αγγλικά και τα γερμανικά, και τα γερμανικά ξεκινούν πλέον πολύ πιο γρήγορα
- Φωνητικές προτάσεις (beta): όταν ο agent θέλει να αλλάξει κάτι με τη φωνή, δείχνει μια κάρτα και περιμένει το ναι σας
- Οι διακομμένες συνεδρίες συνεχίζουν μόνες τους, οι συνεδρίες σε αναμονή περιμένουν τη συσκευή τους και οι κάρτες σχεδίου και ερωτήσεων φτάνουν στον agent της ομάδας
- Επιλέξτε πολλές συνομιλίες για να τις σημειώσετε ως αναγνωσμένες, να τις αρχειοθετήσετε ή να τις διαγράψετε· η αρχειοθέτηση τις κρύβει μόνο για εσάς
- Όλα τα πλαίσια επιλογής είναι πλέον τετράγωνα, η σελίδα Συσκευές δείχνει μία γραμμή ανά υπολογιστή και ένα merge που απορρίφθηκε εμφανίζεται στο νήμα με Επανάληψη
