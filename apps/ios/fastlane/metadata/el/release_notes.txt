- Νήματα: μια συνεδρία ζει πλέον σε ένα νήμα που κρατά τα issues και τις συνεδρίες μιας δουλειάς· ο agent συνδέει τα issues που δημιουργεί ή αναλαμβάνει, μια συνέχιση συνεχίζει τη συζήτηση, και τα Running και Recent εμφανίζουν νήματα
- Σύνταξη: το πεδίο σύνταξης της σελίδας Agent είναι το ένα σημείο για να ξεκινήσετε συνεδρία, με chips για issues ή ένα chip ενέργειας, ελεύθερο κείμενο ως prompt και ένα μενού συν για αρχεία, προσπάθεια, subagents, διακομιστές MCP και Computer use
- Αναζήτηση issues: πληκτρολογήστε # όπου γράφετε για να βρείτε ένα issue με αριθμό ή τίτλο, με την ίδια αναζήτηση σε κάθε εφαρμογή
- Πρώτα βήματα: μια λίστα ελέγχου στη σελίδα Agent οδηγεί μια νέα ομάδα στον πρώτο της πίνακα, την πρώτη συσκευή και την πρώτη συνεδρία
- Ανατροφοδότηση: μια αποτυχημένη ενέργεια εμφανίζει ειδοποίηση, η μη έγκυρη εισαγωγή επισημαίνεται επί τόπου, και οι λίστες δείχνουν σκελετούς όσο φορτώνουν
- Συνεδρίες: workflows, εργασίες και subagents μοιράζονται ένα Work card, ένα script του code mode δείχνει ένα Script card, και ένα σχόλιο που δημοσιεύει ο agent είναι το πραγματικό σχόλιο
- Διακομιστές MCP: οι διακομιστές MCP της ομάδας διαχειρίζονται στις Ρυθμίσεις, και κάθε κενή λίστα διαβάζεται με τον ίδιο τρόπο σε όλη την εφαρμογή
- Λογαριασμοί: μια σύνδεση agent είναι ένα προφίλ ανά email, η σύνδεση με γνωστό email ανανεώνει αυτό το προφίλ, και μια συνεδρία δεν χρησιμοποιεί ποτέ την προεπιλεγμένη σύνδεση του μηχανήματος
- Διορθώσεις: μια συνεδρία που δεν άνοιγε στο iOS ανοίγει ξανά, και το πεδίο σύνταξης κρατά τον σωστό λογαριασμό μετά από αλλαγή συσκευής
