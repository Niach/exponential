Όλα όσα ήρθαν από την 0.14.0:

- Οι agents σας ενημερώνουν όταν μια εκτέλεση τελειώνει: διαβάστε τη σύνοψη και το αποτέλεσμα από παντού και συνεχίστε μια ολοκληρωμένη εκτέλεση από εκεί που σταμάτησε
- Γράψτε # για να ενσωματώσετε ένα chip θέματος σε σχόλια και περιγραφές, με εξυπνότερη συμπεριφορά του δρομέα γύρω από τα chips
- Τα ζωντανά sessions μένουν ήσυχα στις μεγάλες αναμονές αντί να επανασυνδέονται και ανακάμπτουν πιο γρήγορα όταν πέσουν
- Τα ζωντανά coding sessions κρατούν τη σύνδεση σε αλλαγές δικτύου και εναλλαγές εφαρμογών και επανέρχονται μόνα τους όταν πέσουν
- Οι διακόπτες και η λίστα Actions απέκτησαν πιο καθαρή εμφάνιση
- Ξεκινήστε συνομιλία με έναν agent απευθείας από την καρτέλα Agents
- Διαλέξτε προεπιλεγμένο υπολογιστή και κάθε διάλογος έναρξης κώδικα τον προεπιλέγει
- Τα ζωντανά sessions συνεχίζουν να μεταδίδουν όσο κινείστε μέσα στην εφαρμογή και τα πρόχειρα μηνύματα καθοδήγησης επιβιώνουν στις επανασυνδέσεις
- Τέλος οι ειδοποιήσεις για τα δικά σας pull requests
- Απαντήστε στις ερωτήσεις δικαιωμάτων του agent από το κινητό, χωρίς να γυρίσετε στον υπολογιστή
- Επισυνάψτε στιγμιότυπα σε ενεργό coding session και ξεκινήστε κώδικα σε πολλά θέματα μαζί
- Τα sessions δείχνουν σε παύση όσο ο υπολογιστής είναι offline και συνεχίζουν από παντού
- Δώστε σε ένα action πρόγραμμα ή trigger και ένας υπολογιστής σας το τρέχει μόνος του
- Διαχειριστείτε κάθε υπολογιστή από την εφαρμογή: μετονομασία, κοινή χρήση με την ομάδα, καθάρισμα worktrees
- Επιλογέας emoji, εικόνες και αρχεία στα σχόλια και μπάρα μορφοποίησης στον editor
- Οι λίστες θεμάτων ομαδοποιούνται κατά κατάσταση, με πιο καθαρές επικεφαλίδες, ανανεωμένη εμφάνιση και πιο ομαλά μενού δημιουργίας και επιλογής
- Γράψτε # για να συνδέσετε ένα θέμα, οι αναφορές γίνονται ζωντανά chips κατάστασης
- Επιλογή υπεύθυνου, boards που αρχειοθετούνται και λίστα πρώτων βημάτων
- Συνδέστε τα δικά σας GitHub repos και μοιραστείτε τα με την ομάδα
- Διορθώθηκε η αποσύνδεση σε κάθε εκκίνηση, μαζί με πολλές διορθώσεις σταθερότητας και ταχύτητας
