- Guide: τα Changes και Results ενός issue είναι πλέον ένα Guide· κάθε ενότητα της αναφοράς του agent ανοίγει το δικό της diff, το Show complete diff είναι στο κάτω μέρος και το Merge μένει στην κάτω μπάρα όσο το pull request είναι ανοιχτό
- Εκτελέσεις: μια εκτέλεση ανοίγει ως νήμα με γραμμή κατάστασης (συσκευή, χρόνος, τελευταίο εργαλείο) και διαβάζεται γύρο γύρο με τα μηνύματά σας ανάμεσα· το Show work ανοίγει την πλήρη καταγραφή, ένα βέλος πηγαίνει στο νεότερο μήνυμα και η λίστα εργασιών δείχνει την πρόοδο
- Εκτελέσεις: το σήμα του agent γυρίζει όσο δουλεύει, το κεχριμπαρένιο σας περιμένει, το πράσινο έχει ανοιχτό pull request, το μπλε τελείωσε και η εκτέλεση δείχνει Working μέχρι ο agent να τελειώσει πραγματικά
- Σύνταξη: το κουμπί + ανοίγει ένα μενού (υλοποίηση issue, εκτέλεση ενέργειας, αρχείο ή εικόνα έως 50 MB, προσπάθεια, subagents, διακομιστές MCP, Computer use)· οι προτάσεις είναι διακριτικές γραμμές κάτω από το πεδίο
- Σύνδεσμοι: ένας σύνδεσμος σε εκτέλεση ή issue μέσα σε απάντηση του agent ή σε Guide ανοίγει στην εφαρμογή, οι άλλοι στον ενσωματωμένο browser, και τα σκέτα URL πατιούνται
- Στοίβες: ένα μπλοκαρισμένο issue μπορεί να ξεκινήσει ως Stacked PR που χτίζει όλη τη σειρά pull requests από κάτω προς τα πάνω, και ένα στοιβαγμένο pull request συγχωνεύεται με ένα στοιχείο Merge stack
- Ενέργειες: οι αυτοματισμοί είναι πλέον εναύσματα στην ενέργεια που εκτελούν, κάθε ενέργεια είναι σελίδα με prompt, εναύσματα και εκτελέσεις, ένα αποτυχημένο merge προσφέρει Fix merge conflicts, το Tidy up τακτοποιεί έναν πίνακα και η διαγραφή ενέργειας ζητά επιβεβαίωση
- Πλοήγηση: η εφαρμογή ανοίγει στη σελίδα Agent με τις καρτέλες Inbox, Devices, Reviews, Agent και Actions· Reviews, εκτελέσεις, ενέργειες και συσκευές καλύπτουν όλες τις ομάδες σας, και τα Inbox, My issues και Drafts σύρονται πλάγια
- Reviews: ένα pull request από chat ή ενέργεια ανοίγει το Guide του στην εφαρμογή, και ένα pull request με αποθετήριο συνδεδεμένο σε άλλη ομάδα ονομάζει το issue του
- Νέο issue: η δημιουργία issue ανοίγει πλήρη σελίδα με κάθε ιδιότητα, αποθηκευμένη ως πρόχειρο καθώς γράφετε· ένα issue από πρόχειρο σε άλλη συσκευή ανοίγει εδώ, και η έξοδος από πρόχειρο με περιεχόμενο ρωτά Create, Keep as draft ή Discard
- Issues: το Start coding ανοίγει λίστα Ready to code όταν λείπει κάτι, ένα sub-issue ονομάζει το γονικό του και δείχνει πρόοδο με δακτύλιο, οι σχέσεις ομαδοποιούνται σε πτυσσόμενες ενότητες και ο τίτλος μπαίνει στην κεφαλίδα με την κύλιση
- GitHub: μία καθοδηγούμενη σελίδα συνδέει τον λογαριασμό GitHub, εγκαθιστά την εφαρμογή και δείχνει τα αποθετήρια όπου μπορείτε να κάνετε push
- Σχόλια χρηστών: μια υποβολή από το widget είναι issue· απαντήστε στον αναφέροντα από το πεδίο σχολίων και οι απαντήσεις του επιστρέφουν ως σχόλια
- Λογαριασμός: αλλάξτε email με κωδικό, συνδέστε ή αποσυνδέστε συνδέσεις Google, Apple και OIDC όσο μένει άλλος τρόπος εισόδου, και διαχειριστείτε passkeys
- Διακομιστές MCP: συνδέστε μία φορά στο web τον λογαριασμό σας σε διακομιστή MCP της ομάδας, και κάθε εκτέλεση σε οποιοδήποτε μηχάνημα τον χρησιμοποιεί
- Συσκευές: το μπλοκ ετοιμότητας λέει τι χρειάζεται ακόμη ένα μηχάνημα, το Computer use ενεργοποιείται ανά συσκευή και κάθε σύνδεση agent προσφέρει Sign out
- Διάλογοι και ειδοποιήσεις: κάθε επιβεβαίωση και επιλογή χρησιμοποιεί την ίδια κάρτα, το Return δεν επιλέγει ποτέ καταστροφική απάντηση και οι ειδοποιήσεις στοιβάζονται, πατήστε για ανάπτυξη, σύρετε για απόρριψη
- Συμμετοχή σε ομάδα: η πρόσκληση προσφέρει το βήμα συσκευής αν δεν έχετε ακόμη συσκευή, και η εγγραφή με κωδικό email ζητά το όνομά σας
- Διορθώσεις: οι πίνακες δείχνουν ένδειξη φόρτωσης μέχρι να φτάσουν τα issues, το κείμενο συνεδρίας δεν επικαλύπτεται, ένα διπλό κουμπί χάθηκε, μια εκτέλεση σε κενό αποθετήριο ξεκινά και ένας γύρος φινιρίσματος ευθυγραμμίζει γραμμές, αποστάσεις και κείμενα σε όλη την εφαρμογή
