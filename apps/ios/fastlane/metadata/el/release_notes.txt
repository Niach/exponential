- Ενέργειες: οι αυτοματισμοί είναι πλέον εναύσματα στην ενέργεια που εκτελούν, και κάθε ενέργεια είναι μια σελίδα με το prompt, τα εναύσματα και τις εκτελέσεις της
- Οθόνη εργασίας: σύρετε ανάμεσα σε Issue, Run, Changes και Results, και το Changes δείχνει τον αριθμό γραμμών μόλις γίνουν γνωστά τα αρχεία
- Runs: ένα σφάλμα API εμφανίζεται ως ξεχωριστή γραμμή στο ιστορικό αντί για ψευδές όριο χρήσης
- Λογαριασμοί: ο προεπιλεγμένος λογαριασμός ανά συσκευή καταργήθηκε, μια εκτέλεση ξεκινά με τη σύνδεση που χρησιμοποιήσατε τελευταία, εκτός αν επιλέξετε άλλη
- Stacks και batches: πιο διακριτικό σήμα στην κεφαλίδα, μικρότερα chips για issues και ένα συμπαγές γράφημα της σχετικής εργασίας
