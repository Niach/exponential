- Το νέο σύστημα session: ένα thread είναι ένα session που δουλεύει μόνο του και ξυπνά με μηνύματα, με μια κάρτα πλάνου που κάνει μία ερώτηση τη φορά
- Οι agents είναι ορισμοί με δική τους συνομιλία ανά μέλος, triggers που ενεργοποιεί ο server και μια ροή Events· στείλτε μήνυμα σε έναν agent από τον composer
- Τα prompts αντικαθιστούν τις ενέργειες: θα τα βρείτε στο / menu και στις Ρυθμίσεις → Prompts
- Οι προβολές sessions, "σας χρειάζεται" και σε εκτέλεση ακολουθούν το νέο σύστημα σε κάθε οθόνη
