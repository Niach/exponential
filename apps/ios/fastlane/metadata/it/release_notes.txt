- Runs: i workflow non ci sono più, un'esecuzione pianifica e divide da sola il proprio lavoro e avvia da sola le esecuzioni successive
- Issue bloccate: avviarne una chiede Cancel, Start anyway o Stacked PR, che costruisce l'intera catena di pull request dal basso verso l'alto
- Merge: Merge su una pull request impilata chiede Merge stack o Merge this pull request
- Schermata di lavoro: i selettori, il pannello di utilizzo e il pannello dei file si aprono al primo tocco
- Scheda Run: la trascrizione scorre sotto il campo di scrittura, così le ultime righe restano raggiungibili
