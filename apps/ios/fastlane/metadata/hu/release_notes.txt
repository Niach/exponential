- Runs: megszűntek a workflow-k, a futás maga tervezi meg és osztja fel a munkáját, és magától indítja a folytató futásokat
- Blokkolt issue-k: indításkor a Cancel, Start anyway vagy Stacked PR közül választhatsz, ez utóbbi alulról felfelé felépíti a pull requestek teljes sorát
- Merge: egy egymásra épülő pull requesten a Merge rákérdez: Merge stack vagy Merge this pull request
- Munkanézet: a választók, a használati lap és a fájllap már az első koppintásra megnyílnak
- Run fül: az átirat a szerkesztőmező alá görget, így az utolsó sorai is elérhetők maradnak
