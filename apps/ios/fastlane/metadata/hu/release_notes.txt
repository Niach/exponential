- Szál fejléc: már semmi sem görget, az issue-k és sessionök "+N"-be csukódnak, ha elfogy a hely, az al-issue-k és mélyebb sessionök pedig egy koppintással nyílnak
- Issue csatolása: a Conversation melletti "+" a Link an issue és New issue lehetőséget kínálja
- Al-sessionök: egy al-session kérdései és tervei a szál beszélgetésében jelennek meg, és ott helyben megválaszolhatók
- Egy szövegmező: a szál, egy session és egy új indítás egy mezőn osztozik, "Type / for commands", képpel, fájllal, # jellel és emojival a mezőben
- Beállítások session közben: a Plan mód azonnal vált, az erőfeszítés, a computer use és az MCP szerverek pedig a következő üzenettől érvényesek
- Issue állapot: a csatolt issue In progress állapotba kerül, egy pull request In review állapotba, összevonás után pedig Done állapotba viszi
