- Guide: egy issue Changes és Results nézete mostantól egyetlen Guide; az agent jelentésének minden szakasza saját diffet nyit, a Show complete diff pedig legalul található
- Futtatások: a futtatás szála körről körre olvasható, köztük a saját üzeneteiddel, és egy egymásra épülő pull request egyetlen Merge stack vezérlővel egyesíthető
- Szerkesztő: a + gomb egyetlen menüt nyit (issue megvalósítása, művelet futtatása, legfeljebb 50 MB-os fájl vagy kép hozzáadása, ráfordítás, alagentek, MCP-szerverek, számítógép-használat); a javaslatok visszafogott sorok a mező alatt
- Hivatkozások: egy agent válaszában vagy a Guide-ban lévő, futtatásra vagy issue-ra mutató hivatkozás az appban nyílik meg, a többi hivatkozás az app böngészőjében, a puszta URL-ek pedig koppinthatók
- Műveletek: sikertelen egyesítéskor a Fix merge conflicts jelenik meg, egy beépített művelet, amely rebase-el, feloldja az ütközéseket és egyesíti a pull requestet
- Javítások: a Reviews megnevezi annak a pull requestnek az issue-ját, amelynek repója egy másik csapatban van csatlakoztatva, a munkamenet szövege már nem fedi egymást, eltűnt egy duplikált gomb, és egy finomhangolási kör egységesíti a sorokat, térközöket és szövegeket az egész appban
