- Ecranul de lucru: Issue, Rulare, Modificări și Rezultate sunt file glisabile în antet, cu Merge alături cât timp pull request-ul este deschis
- Settings > Account: schimbă-ți adresa de email cu un cod, conectează sau deconectează autentificările Google, Apple și OIDC și gestionează cheile de acces
- La îmbinarea unui pull request dintr-un stack, aplicația întreabă dacă să îmbine tot stack-ul sau doar acest pull request
- Rezultate: raportul unei rulări apare lângă capturile de ecran, capturile lungi se deschid într-un vizualizator cu derulare, iar o notificare poate deschide direct Rezultate
- Atașamentele Markdown se deschid într-o previzualizare în aplicație
- Notificări: un singur stil, suprapus, peste tot, atinge pentru a extinde, glisează pentru a închide
- Tidy up: o acțiune integrată pentru ordonarea boardurilor, cu pictograme potrivite pentru stackuri, loturi și workflow-uri
- Sub-issue-urile create cu un atașament nu mai lasă în urmă o ciornă
