- En-tête du fil : plus rien ne défile, les issues et les sessions se replient en "+N" quand la place manque, et les sous-issues et sessions plus profondes s'ouvrent d'un toucher
- Lier un issue : le "+" à côté de Conversation propose Link an issue et New issue
- Sous-sessions : les questions et les plans d'une sous-session apparaissent dans la conversation du fil et se règlent sur place
- Un seul champ de saisie : le fil, une session et un nouveau départ partagent un champ, "Type / for commands", avec image, fichier, # et emoji dans le champ
- Options en cours de session : le mode Plan bascule aussitôt, et l'effort, computer use et les serveurs MCP s'appliquent dès le message suivant
- Statut de l'issue : lier un issue le passe en In progress, et une pull request le passe en In review puis, une fois fusionnée, en Done
