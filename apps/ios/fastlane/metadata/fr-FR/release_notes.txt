- Relations entre issues : liez des issues comme parent, sous-issue, bloque, bloquée par, doublon ou liée depuis la feuille de propriétés ; taper #EXP-12 dans une description ou un commentaire lie les deux issues tout seul
- Commentaires en fil : répondez sous un commentaire depuis le champ ancré ; les fils restent sur un seul niveau, et un commentaire posté par un agent via MCP l'indique dans son en-tête
- Un premier lancement guidé : créer une équipe vous fait passer par le premier board, les invitations de coéquipiers et la configuration des appareils, dans le même ordre que sur le web et le bureau
- Réglages de l'équipe : les propriétaires peuvent créer des liens d'invitation depuis la section « Members »
- Merge depuis les exécutions d'actions et de chat : une exécution qui a ouvert une pull request affiche « Merge » dans sa vue de pilotage, et Reviews liste ces pull requests sous « Agent runs »
- Images de commentaires plus grandes : les images jointes à un commentaire s'affichent sur toute la largeur et ouvrent la visionneuse d'une touche
- Un flux d'activité plus calme : les événements tiennent sur une ligne discrète avec une heure, les commentaires restent dans une seule carte
- Le bouton « Subscribe » disparaît : vous suivez une issue automatiquement quand vous la créez, la commentez, qu'elle vous est assignée ou que vous y êtes mentionné
- Pilotage : la barre de contexte ne recouvre plus la transcription
