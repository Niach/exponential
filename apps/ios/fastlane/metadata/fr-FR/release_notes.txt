- Workflows : une rangée de chips choisit un nœud et l'ouvre sur Issue, Run, Changes et Results, une question du planificateur s'affiche dans une bannière, Pause et Dismiss se trouvent dans le menu d'options, et la pull request finale apparaît dans Reviews, où elle se fusionne
- Runs de l'agent : les runs d'un workflow se regroupent sous leur nœud avec un point d'état et une légende, les runs de revue portent leur titre, un run qui vous attend affiche un point, et la feuille Recent dessine l'arbre
- Issues : le badge de blocage ouvre un mini-graphe dessiné sur une seule grille commune, et l'en-tête d'un run en stack ou par lot montre l'issue de tête avec un compteur
- Éditeur : taper --- insère aussitôt un séparateur
- Activité : les changements d'estimation se regroupent comme toute autre modification de champ
