- Runs: workflows er væk, en kørsel planlægger og deler selv sit arbejde op og starter selv opfølgende kørsler
- Blokerede issues: når du starter et, kan du vælge Cancel, Start anyway eller Stacked PR, som bygger hele rækken af pull requests nedefra og op
- Merge: Merge på en stacked pull request giver valget Merge stack eller Merge this pull request
- Arbejdsskærm: vælgere, forbrugsarket og filarket åbner ved første tryk
- Fanen Run: transskriptionen ruller ind under skrivefeltet, så de sidste linjer altid kan nås
