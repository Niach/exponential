- Runs: Workflows gibt es nicht mehr, ein Lauf plant und teilt seine Arbeit selbst auf und startet Folgeläufe von sich aus
- Blockierte Issues: beim Starten fragt die App Cancel, Start anyway oder Stacked PR, das die ganze Reihe von Pull Requests von unten nach oben aufbaut
- Mergen: Merge bei einem gestapelten Pull Request fragt nach Merge stack oder Merge this pull request
- Arbeitsansicht: Auswahllisten, das Nutzungsblatt und das Dateiblatt öffnen sich beim ersten Tippen
- Run-Tab: der Verlauf scrollt unter das Eingabefeld, sodass seine letzten Zeilen erreichbar bleiben
