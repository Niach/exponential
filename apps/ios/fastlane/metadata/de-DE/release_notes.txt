- Pläne öffnen sich auf einer eigenen Seite, mit Gliederung und ihren Bildern
- Ruhigere Stories: eine Karte pro Plan oder Ergebnis, jede mit Kennzeichnung
- Neue App öffnet sofort den Editor, und der Agent gibt deiner App einen Namen
- Die Arbeitszeile zeigt, welches Tool der Agent gerade schreibt und wie lange schon
- Schnellantworten über dem Eingabefeld sind besser lesbar
- Apps bekommen im Editor die Tabs Chat, Daten, Versionen und Einstellungen
- Einstellungen › MCP ist eine Seite für deine MCP-Server, App-Tools und Aktivitäten
- Live-Sitzungen streamen Ende-zu-Ende-verschlüsselt weiter, wenn die direkte Verbindung zum Gerät abbricht
- Text, den du tippst, während ein Kommentar gesendet wird, bleibt im Eingabefeld
- Ein Thread zeigt die Aufgaben seiner laufenden Untersitzung
- Agenten bekommen das Issue, das du ihnen gibst: Kennung, Titel und Beschreibung
- Die Thread-Kopfzeile zeigt den Status der Sitzung und eine Merge-Schaltfläche
- Story-Beschriftungen werden nie größer als der Viewer
- Schließe eine Frage oder einen Plan, den du nicht beantworten willst; die Thread-Kopfzeile zeigt, was noch wartet
- Die Geräteseite zeigt jedes Gerät als Karte
- Chats, der Bildschirm für neue Chats und die Einstellungen sehen aus wie in den anderen Apps
- In Bilder zoomen: jede Bildansicht zoomt und verschiebt
- Claude bleibt standardmäßig angemeldet: eine neue Anmeldung hält ein Jahr
- Breite Tabellen scrollen seitlich, statt ihre Spalten zu quetschen
- Die Merge-Schaltfläche zeigt die CI-Checks deines Pull Requests
- Die Arbeit einer Sitzung wird laufend gesichert, so geht sie auf jedem Gerät weiter
- Dauerhaft angemeldete Logins zeigen ihre 5-Stunden- und Wochennutzung
- Zeiten lauten „gerade eben“ statt „in 0 Sekunden“
- Eine wartende Sitzung auf einem Offline-Gerät wechselt auf dein anderes Gerät
- Ein Start, der nie begonnen hat, zeigt „Konnte nicht starten“ statt untätig zu warten
- Mehrere unterbrochene Sitzungen lassen sich gleichzeitig fortsetzen
- Chats öffnen schneller und bleiben flüssig, während ein Agent arbeitet: Live-Updates zeichnen nicht mehr den ganzen Chat oder das Eingabefeld neu, lange Verläufe laden ohne Hänger, und die Verbindung zu deinen Geräten erholt sich in Sekunden
- Live-Chats zeichnen weniger neu, während ein Agent arbeitet, damit das Scrollen flüssig bleibt
- App-Einträge gehören ihrem Autor; Team-Owner können Einträge für andere anlegen
- Agenten können kleine Animationen in ihren Karten zeigen
