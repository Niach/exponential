- Das neue Session-System: ein Thread ist eine Session, die selbst arbeitet und von Nachrichten geweckt wird, mit einer Plan-Karte, die jeweils eine Frage stellt
- Agents sind Definitionen mit einer eigenen Unterhaltung pro Mitglied, vom Server ausgelösten Triggern und einem Events-Stream; schreib einem Agent direkt aus dem Composer
- Prompts ersetzen Aktionen: du findest sie im / menu und unter Einstellungen → Prompts
- Die Ansichten Sessions, Braucht dich und Laufend folgen auf jedem Bildschirm dem neuen System
