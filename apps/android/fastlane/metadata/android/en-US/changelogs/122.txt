Workflows: plan backlog issues of one repository as a graph of what blocks what and let a device run them in parallel; pull requests land in dependency order, a separate run reviews each one, and one final pull request carries the whole diff. Sub-issues sit under their parent in every list, a badge counts what blocks a row and opens the dependency graph, and starting a blocked issue offers Cancel, Start anyway or a stacked pull request. The chat and New issue buttons show on every tab.
