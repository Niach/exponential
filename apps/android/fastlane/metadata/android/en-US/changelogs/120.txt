Every diff reads the same: files sit in a tree you can jump around, and an agent's edits in a turn collect in one Edited files card. Usage lives in one overlay with the run's own account, its limit windows and the context window, and Devices lists each machine's logins with plan, health and usage. One issue search drives every list, picker and # menu. A chat run takes its name from the agent's work, a running command shows only its last lines, and a run that goes quiet stays in the list.
